🌸 Greedy Algorithm

Flower Order Fulfillment using Minimum Cost Strategy

💡 How the Greedy Algorithm Works

The system fulfills a customer's flower requirement by selecting the available flower with the lowest price first. It takes as many flowers as possible from that type and then moves to the next lowest priced flower until the required quantity is fulfilled.

  1. Find the available flower with the lowest price.
  2. Take as many flowers as required from that type.
  3. If more flowers are required, move to the next lowest-priced flower.
  4. Continue until the customer's requirement is fulfilled.
