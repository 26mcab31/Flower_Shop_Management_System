Linear Search

Linear Search checks each flower one by one until the required flower is found.

In this project, Linear Search is used to search flowers by their name.

How it works:
  1. Start from the first flower.
  2. Compare its name with the search name.
  3. If the name matches, the flower is found.
  4. If it does not match, move to the next flower.
  5. Continue until the flower is found or the list ends.
