Bubble Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

In this project, Bubble Sort is used to arrange flowers according to their Flower ID.

How Bubble Sort works:
  1. Start from the first flower.
  2. Compare two adjacent flower IDs.
  3. If the first ID is greater than the second ID, swap them.
  4. Continue comparing the next pair.
  5. Repeat the process until all flowers are sorted.
