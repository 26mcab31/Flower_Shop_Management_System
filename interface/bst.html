🌳 Flower Binary Search Tree

Binary Search Tree

Flowers are stored in the Binary Search Tree according to their Flower ID.

Smaller IDs are placed on the left side. Larger IDs are placed on the right side.

Inorder Traversal visits: Left → Root → Right

Example:

Add IDs: 103, 101, 102

Inorder result: 101 → 102 → 103
